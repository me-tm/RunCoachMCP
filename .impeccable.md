## Design Context

### Users
Personal tool that could go public. Primary user is a runner/cyclist who's already technical enough to run an MCP server. Occasional visitors setting up connections to Strava and Garmin. Interface is visited briefly: connect an account, test the connection, move on. No sustained daily use.

### Brand Personality
Fast. Precise. Athletic. Like a sports device, not a SaaS product. The tool should feel like equipment you trust, not an app you market.

### Aesthetic Direction
**Dark theme** — athletes use this in early morning or late evening training contexts. Dark background with blue-tinted near-black surfaces.

**Bold & technical typography** — Big Shoulders Display (900wt) for headings, Barlow Condensed for UI labels and status, Barlow for body. Strong size contrast between display and body.

**Connector-branded panels** — Strava orange and Garmin blue as top-border accents on their respective panels. LED-green glowing dot for connected state.

**No white card box** — dark background IS the design. Two panels float on it directly.

Anti-references: generic SaaS dashboards, purple-gradient AI aesthetics, glassmorphism.

### Design Principles
1. **Equipment, not app** — every detail should feel precise and functional, like a Garmin device menu
2. **Connector identity** — Strava and Garmin have strong brand colors; lean into them as anchors
3. **Status is primary** — the first thing a user needs to know is what's connected; make status unmissable
4. **No decoration for decoration's sake** — every visual element earns its place
5. **Left-aligned within panels** — centered masthead, left-aligned panel content for editorial feel
